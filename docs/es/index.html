Prompts para Suno de música latina y DJ edits

Elige género y mood: obtienes la línea de Style y las etiquetas para Suno. Pega tu letra: ves las sílabas cantadas por línea, las rimas y cada error de etiquetas, en español, portugués o inglés.

Escribir un prompt ↓Revisar mi letra

Suno Latin Producer es una herramienta gratis y de código abierto de HablaMusic que escribe prompts de estilo y estructuras para Suno en 39 géneros, entre ellos reggaetón, dembow, cumbia, bachata, corridos tumbados y funk carioca, y revisa letras contando las sílabas cantadas en español y portugués (con sinalefa) y marcando errores de etiquetas. El modo DJ edit pide intro y outro instrumentales para poder mezclar la pista.

1. Escribe un prompt para Suno

Elige el sonido. Recibes tres líneas de Style que cambian una sola cosa cada una (pruébalas en A/B), las etiquetas para pegar en Lyrics y cuántas líneas y sílabas necesita cada sección.

2. Revisa tu letra

Pega la letra con etiquetas [Sección]. El revisor cuenta las sílabas como se cantan y aplica las 17 reglas. Tu texto no sale de tu navegador.

Cómo funciona

Línea de Style

Primero el género, luego tempo y tonalidad, dos palabras de mood, dos o tres instrumentos, una de producción, la voz y el idioma, en una sola línea. Sin nombres de artistas: Suno los rechaza.

Etiquetas

Una etiqueta en inglés por línea: [Intro], [Verse 1], [Chorus], [Hook], [Outro]. Una etiqueta traducida como [Coro] se puede cantar.

Líneas parejas

Suno no puede estirar una línea. Mantén las líneas de una sección a unas dos sílabas cantadas entre sí; "te amo" cuenta como dos.

DJ edit

Deja [Intro] y [Outro] vacíos y pide intro y outro instrumentales extendidos, para poder cuadrar la pista.

Úsalo en la terminal o desde un agente de IA

Python 3.9+, sin paquetes. Los mismos scripts hacen funcionar esta página.

git clone https://github.com/hablamusic/suno-latin-producer
cd suno-latin-producer
python3 scripts/brief.py --genre reggaeton --mood playful --lang es --dj
python3 scripts/lyric_meter.py examples/lyrics/luna-de-neon.es.txt

# como skill de agente (Claude Code, Cursor, Codex)
npx skills add hablamusic/suno-latin-producer

Preguntas frecuentes

¿Cómo escribo un prompt de Suno para reggaetón?

Todo en una línea, lo más importante primero: reggaeton, 94 BPM, F minor, playful, bouncy, dembow drums, deep 808 bass, sub-heavy club mix, warm male vocal, Spanish-language vocals. Elige reggaetón arriba y la herramienta lo escribe con dos variantes. Más en la guía de prompts para Suno.

¿Las etiquetas de Suno van en español?

No. Deja las etiquetas en inglés, como [Chorus] y [Verse 1]. Suno lee las etiquetas en inglés como estructura y puede cantar una traducida como [Coro]. Solo la letra va en español.

¿Por qué Suno acelera o corta algunas líneas?

Esas líneas son más largas que el resto de la sección. Mantén cada línea a unas dos sílabas cantadas de las demás. El revisor muestra el conteo por línea y avisa cuando una se desvía.

¿Cómo hago una canción con IA que un DJ pueda mezclar?

Marca DJ edit: la línea de Style pide intro y outro instrumentales extendidos y el revisor avisa si [Intro] u [Outro] tienen líneas cantadas. Luego confirma el BPM y la tonalidad reales con el detector de BPM y tonalidad, porque la IA suele ignorar la tonalidad del prompt.

¿Es gratis? ¿Envía mi letra a algún lado?

Gratis y de código abierto (MIT). Los scripts de Python corren dentro de tu navegador con Pyodide; tu letra nunca se sube.
