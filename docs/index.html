Suno prompts for Latin music and DJ edits

Pick a genre and a mood: get the Style line and the tag layout for Suno. Paste your lyrics: see the sung syllables per line, the rhymes and every tag problem, in Spanish, Portuguese or English.

Write a prompt ↓Check my lyrics

Suno Latin Producer is a free, open-source tool from HablaMusic that writes Suno style prompts and song structures for 39 genres, including reggaeton, dembow, cumbia, bachata, corridos tumbados and funk carioca, and checks lyrics by counting sung syllables in Spanish and Brazilian Portuguese (with sinalefa) and flagging tag mistakes. A DJ-edit mode asks for instrumental intros and outros so the track can be mixed.

1. Write a Suno prompt

Choose the sound. You get three Style lines that differ in one thing each (A/B test them), the tags to paste into Lyrics, and how many lines and syllables each section needs.

2. Check your lyrics

Paste lyrics with [Section] tags. The checker counts syllables the way they are sung and runs the 17 lint rules. Your text stays in your browser.

How it works

Style line

Genre first, then tempo and key, two mood words, two or three instruments, a production word, the vocal and the language, on one line. No artist names: Suno rejects them.

Tags

One English tag per line: [Intro], [Verse 1], [Chorus], [Hook], [Outro]. Translated tags like [Coro] can be sung aloud.

Even lines

Suno cannot stretch a line. Keep lines in a section within about two sung syllables of each other; in Spanish "te amo" counts as two.

DJ edit

Leave [Intro] and [Outro] empty and ask for an extended instrumental intro and outro, so the track can be beatmatched.

Run it in the terminal or from an AI agent

Python 3.9+, no packages. The same scripts run this page.

git clone https://github.com/hablamusic/suno-latin-producer
cd suno-latin-producer
python3 scripts/brief.py --genre reggaeton --mood playful --lang es --dj
python3 scripts/lyric_meter.py examples/lyrics/luna-de-neon.es.txt

# as an agent skill (Claude Code, Cursor, Codex)
npx skills add hablamusic/suno-latin-producer

FAQ

How do I write a Suno prompt for reggaeton?

Put everything on one line, most important first: reggaeton, 94 BPM, F minor, playful, bouncy, dembow drums, deep 808 bass, sub-heavy club mix, warm male vocal, Spanish-language vocals. Pick reggaeton above and the tool writes it with two variants. More in the Suno prompts guide.

Should Suno tags be in Spanish or Portuguese?

No. Keep tags in English, like [Chorus] and [Verse 1]. Suno reads English tags as structure and may sing a translated tag such as [Coro] or [Refrão]. Only the lyrics are in your language.

Why does Suno rush or cut some lines?

Those lines are longer than the rest of the section. Keep each line within about two sung syllables of the others. The checker shows the count per line and warns when a line drifts.

How do I make an AI song a DJ can mix?

Tick DJ edit: the Style line asks for an extended instrumental intro and outro, and the checker warns if [Intro] or [Outro] have sung lines. Then confirm the real BPM and key with the BPM and key finder, because AI models often ignore the key in the prompt.

Is it free? Does it send my lyrics anywhere?

Free and open source (MIT). The Python scripts run inside your browser with Pyodide; your lyrics are never uploaded.
