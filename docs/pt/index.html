Prompts para Suno de funk, música latina e versões DJ

Escolha o gênero e o clima: você recebe a linha de Style e as tags para o Suno. Cole sua letra: veja as sílabas cantadas por linha, as rimas e cada erro de tag, em português, espanhol ou inglês.

Escrever um prompt ↓Revisar minha letra

Suno Latin Producer é uma ferramenta grátis e open source da HablaMusic que escreve prompts de estilo e estruturas para o Suno em 39 gêneros, entre eles funk carioca, piseiro, sertanejo, pagode, reggaeton e cumbia, e revisa letras contando as sílabas cantadas em português e espanhol (com elisão) e apontando erros de tags. O modo versão DJ pede intro e outro instrumentais para dar para mixar a faixa.

1. Escreva um prompt para o Suno

Escolha o som. Você recebe três linhas de Style que mudam uma coisa só cada uma (teste A/B), as tags para colar em Lyrics e quantas linhas e sílabas cada parte precisa.

2. Revise sua letra

Cole a letra com tags [Seção]. O revisor conta as sílabas como são cantadas e aplica as 17 regras. Seu texto não sai do navegador.

Como funciona

Linha de Style

Primeiro o gênero, depois andamento e tom, duas palavras de clima, dois ou três instrumentos, uma de produção, a voz e o idioma, numa linha só. Sem nome de artista: o Suno recusa.

Tags

Uma tag em inglês por linha: [Intro], [Verse 1], [Chorus], [Hook], [Outro]. Uma tag traduzida como [Refrão] pode ser cantada.

Linhas iguais

O Suno não estica uma linha. Mantenha as linhas de uma parte a umas duas sílabas cantadas umas das outras; "te amo" conta como duas.

Versão DJ

Deixe [Intro] e [Outro] vazios e peça intro e outro instrumentais estendidos, para dar para casar a batida.

Use no terminal ou num agente de IA

Python 3.9+, sem pacotes. Os mesmos scripts rodam nesta página.

git clone https://github.com/hablamusic/suno-latin-producer
cd suno-latin-producer
python3 scripts/brief.py --genre "funk carioca" --mood euphoric --lang pt --dj
python3 scripts/lyric_meter.py examples/lyrics/baile-na-laje.pt.txt

# como skill de agente (Claude Code, Cursor, Codex)
npx skills add hablamusic/suno-latin-producer

Perguntas frequentes

Como escrevo um prompt do Suno para funk?

Tudo numa linha, o mais importante primeiro: funk carioca, 130 BPM, A minor, euphoric, anthemic, tamborzão drums, 808 bass, raw baile funk production, warm male vocal, Brazilian Portuguese vocals. Escolha funk carioca acima e a ferramenta escreve com duas variantes. Mais no guia de prompts para Suno.

As tags do Suno vão em português?

Não. Deixe as tags em inglês, como [Chorus] e [Verse 1]. O Suno lê tags em inglês como estrutura e pode cantar uma traduzida como [Refrão]. Só a letra fica em português.

Por que o Suno corre ou corta algumas linhas?

Essas linhas são mais longas que o resto da parte. Mantenha cada linha a umas duas sílabas cantadas das outras. O revisor mostra a contagem por linha e avisa quando uma foge.

Como faço uma música com IA que dá para mixar?

Marque versão DJ: a linha de Style pede intro e outro instrumentais estendidos e o revisor avisa se [Intro] ou [Outro] têm linhas cantadas. Depois confira o BPM e o tom reais com o detector de BPM e tom, porque a IA costuma ignorar o tom do prompt.

É grátis? Envia minha letra para algum lugar?

Grátis e open source (MIT). Os scripts em Python rodam dentro do seu navegador com Pyodide; sua letra nunca é enviada.
